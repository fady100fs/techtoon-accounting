# 🛠️ Techtoon Accounting C+ — ملفات الإصلاح

## المشاكل التي تم حلها

### 1️⃣ خطأ `column i.cash_box_id does not exist`
**السبب:** نموذج EF Core يتوقع وجود عمود `cash_box_id` في جدول `invoices`، لكنه غير موجود في قاعدة بيانات PostgreSQL.

**الحل:** ملف `fix_database.sql` يضيف العمود المفقود وجميع الأعمدة الأخرى الضرورية، بالإضافة إلى إنشاء جدول `invoice_payments` للدفع المتعدد.

---

### 2️⃣ البحث عن الأصناف (بحث فوري ذكي)
**المشكلة:** لم يكن هناك بحث فوري — مجرد زر "إضافة صنف".

**الحل الآن:**
- عند كتابة **أي حرف أو رقم** في خلية "الصنف"، يظهر مباشرة قائمة بالأصناف المطابقة
- البحث يشمل: **الاسم** أو **الباركود** أو **SKU**
- النتائج تظهر فوراً في نافذة منبثقة (Popup) أسفل حقل البحث
- كل نتيجة تعرض: الاسم، الباركود، والمخزون المتاح
- التنقل بالأسهم ⬆️⬇️ ثم Enter للاختيار، أو النقر بالماوس
- Escape للإغلاق

---

### 3️⃣ قسم الدفع متعدد الطرق
**المشكلة:** القسم لم يكن يظهر في أسفل الفاتورة.

**الحل الآن:**
- قسم "طرق الدفع المتعددة" يظهر **دائماً** في أسفل الفاتورة (قبل الإجماليات)
- زر "+ إضافة دفعة" لإضافة طرق دفع متعددة
- كل دفعة تحتوي على:
  - **طريقة الدفع:** نقدي / بطاقة / تحويل بنكي / شيك / آجل
  - **المبلغ**
  - **مرجع / رقم** (رقم الشيك أو العملية)
  - **تاريخ الدفع**
  - **ملاحظات**
- يتم حساب المدفوع والمتبقي تلقائياً

## ⚙️ تفاصيل تقنية

### كيف يعمل البحث الفوري؟
في `InvoiceLineItem.SearchText` (الخاصية المرتبطة بحقل البحث):
```
عند تغيير النص → ApplySearch()
  → يفلتر _allItems بالاسم أو الباركود أو SKU
  → يأخذ أول 15 نتيجة
  → يحدّث FilteredItems
  → يفتح الـ Popup (IsPopupOpen = true)
```

### كيف يعمل الدفع المتعدد؟
- `Payments` مجموعة من `InvoicePaymentRow`
- كل صف = طريقة دفع واحدة
- `TotalPaid` = مجموع كل المبالغ
- `Remaining` = الإجمالي - المدفوع
- عند الحفظ: كل دفعة تُحفظ في جدول `invoice_payments`

### مرونة اتصال قاعدة البيانات
الـ ViewModel يبحث عن سلسلة الاتصال بالترتيب:
1. متغير البيئة `TECHTOON_PG_CONNECTION`
2. ملف `appsettings.json`
3. القيمة الافتراضية (Neon PostgreSQL)
