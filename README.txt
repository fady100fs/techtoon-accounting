============================================================
  Techtoon Accounting - نظام المحاسبة المتكامل
  دليل التثبيت والتشغيل
============================================================

المتطلبات:
-----------
- Windows 10 أو أحدث
- Python 3.11 أو أحدث (https://www.python.org/downloads/)
- اتصال بالإنترنت (للتثبيت الأولي فقط)

التثبيت الأولي:
---------------
1. تأكد من تثبيت Python على جهازك
2.双击 (انقر مرتين) على ملف: install.bat
3. انتظر حتى اكتمال التثبيت
4. سيظهر اختصار على سطح المكتب

تشغيل البرنامج:
---------------
الطريقة 1: انقر على اختصار "Techtoon Accounting" على سطح المكتب
الطريقة 2:双击 على ملف: run.bat
الطريقة 3: افتح Terminal واكتب: streamlit run app.py

تسجيل الدخول الافتراضي:
-----------------------
اسم المستخدم: admin
كلمة المرور: admin123

تحويل إلى ملف EXE (اختياري):
----------------------------
إذا أردت ملف EXE واحد يعمل بدون Python:
1.双击 على ملف: build_exe.bat
2. انتظر حتى اكتمال البناء (5-10 دقائق)
3. ستجد الملف في: dist\Techtoon Accounting.exe

النسخ الاحتياطي:
---------------
- جميع بياناتك محفوظة في ملف: accounting.db
- قم بنسخ هذا الملف دورياً للنسخ الاحتياطي
- استخدم صفحة "النسخ الاحتياطي" في البرنامج

الدعم الفني:
-----------
إذا واجهت أي مشكلة:
1. تأكد من تثبيت Python بشكل صحيح
2. شغّل ملف install.bat مرة أخرى
3. تحقق من أن جميع الملفات في نفس المجلد
